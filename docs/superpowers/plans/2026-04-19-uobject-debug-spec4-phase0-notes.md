### Envelope shape (established from source)

```json
{
  "<ObjectName>": {
    "LogServer":  { ... },
    "Timers":     { "count": N, "<id>": { "id":, "name":, "msec":, "timeleft":, "tick": } },
    "Variables":  { "name": value, ... },
    "Statistics": { "processingMessageCatchCount": N,
                    "sensors": { "<name>": { "id":, "name":, "count": } } },
    "io":         { "in":  { "<portName>": { "id": N, "value": X } },
                    "out": { "<portName>": { "id": N, "value": X } } }
  }
}
```

### Decisions for Phase 1

- `debug.Snapshot` Go struct (Task 1.1) mirrors this shape via
  flatten adapter:
  - `Inputs []Port` ← `io.in[name] → {id, name, value}`
  - `Outputs []Port` ← `io.out[name] → {id, name, value}`
  - `Variables map[string]any` ← `Variables` verbatim
  - `Timers []Timer` ← flatten `Timers` map (exclude "count" key),
    rename `msec → interval_ms`, `timeleft → time_left`
  - `Statistics map[string]any` ← `Statistics` verbatim
  - `SMObject "SharedMemory"` ← panel-side default (not in uniset
    response; panel resolves via config)
- LogServer field dropped (not needed by Spec 4).
- No `trace` section in Snapshot — trace has its own endpoint.
